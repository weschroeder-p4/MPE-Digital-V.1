## Publicar no GitHub Pages
1. Crie um repositório público e suba o **conteúdo** desta pasta na raiz (index.html, CNAME, favicons, assets/…).
2. Settings → Pages → Source: branch `main`, pasta `/ (root)`.
3. No Cloudflare: CNAME `mped` → `SEU_USUARIO.github.io`, em **DNS only** (nuvem cinza).
4. Settings → Pages → Custom domain: `mped.p4gestao.com.br`. Aguarde "DNS check successful".
5. Marque **Enforce HTTPS**.

> A API de Conversões (CAPI) da Meta é configurada no painel da Greenn, nunca no HTML.
